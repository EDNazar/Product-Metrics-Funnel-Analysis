# Product-Metrics-Funnel-Analysis

В данном проекте проводится расчет ключевых метрик, показывающих здоровье продукта, а также построение воронки продаж для сайта создания объявлений. 

## Цели проекта

1. **Посчитать метрики, показывающие здоровье продукта**
   - **DAU/WAU/MAU** — вовлеченность
   - **CR (Conversion Rate)** — конверсия в целевое действие
   - **Retention** — удержание пользователей
   - **LTV (Lifetime Value)** — пожизненная стоимость клиента
   - **ARPPU** — средний доход с одного платящего пользователя

2. **Построить воронку**: как пользователи доходят до создания объявления

### Шаги воронки
-**Визит** - пользователь зашёл на сайт
-**Поиск** - начал искать**
-**Создание** - дошел до публикации объявления**



## Структура проекта

- **create_tables.sql** - здесь создается база данных пользователей
- **metrics_and_funnel.sql** - - содержит расчет метрик и построение воронки
